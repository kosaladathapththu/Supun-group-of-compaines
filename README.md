# Supun Group of Companies — Website

A premium, responsive corporate website for Supun Group of Companies.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```powershell
npx serve .
```

## Content and media

All supplied company, leadership, product, award, and contact content is included. Image areas are intentionally presented as labelled photography placeholders and can be replaced when the final photo library is ready.

## Deployment

The site is dependency-free and can be deployed to GitHub Pages, Netlify, Cloudflare Pages, or any standard web host.
